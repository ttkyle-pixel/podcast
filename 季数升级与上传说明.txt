名扬海外 FFC · 季数栏目与浏览数升级
==================================

一、把升级代码上传到 GitHub

1. 解压“INSIDE_FFC_Cloudflare_Update.zip”。
2. 打开原来的 GitHub 仓库 podcast。
3. 点击 Add file，再点击 Upload files。
4. 把解压后的全部文件和文件夹拖到上传区域。
5. 确认页面显示多个文件被修改或新增，然后点击 Commit changes。
6. 等待 Cloudflare 自动部署完成。部署命令会自动给数据库增加“季数”和“浏览数”字段。

升级不会删除现有作品、封面、音频或文字。现有作品会自动归入第二季。
原有作品的浏览数从 0 开始。

二、检查当前第二季作品

1. 登录线上网址后面的 /admin。
2. 找到现有作品，点击“编辑”。
3. “栏目季数”选择“第二季”。
4. “期数”只填写 Vol.01，不要再填写 Season2 Vol.01。
5. 点击“发布 / 更新”。

三、上传第一季作品

1. 在后台点击“＋ 新建作品”。
2. “栏目季数”选择“第一季”。
3. “期数”填写 Vol.01、Vol.02 等。
4. 填写标题、主播、嘉宾、摘要和文字版。
5. 选择对应的封面和音频。
6. 点击“发布 / 更新”。

首页会自动出现“第二季”和“第一季”两个栏目。以后新增第三季时，可以再扩展选项；目前后台预设第一季和第二季。

四、浏览数怎么计算

1. 读者每打开一次作品，浏览数都会自动增加 1 次。
2. 同一台手机或电脑当天重复打开、关闭后重开或刷新页面，也会继续累计。
3. 作品卡片、文字详情页和后台作品列表都会显示浏览数。
4. 不需要在后台手动填写或修改浏览数。

注意：
- 不要在期数中重复填写 Season1 或 Season2。
- 音频单个不超过 80MB，封面不超过 10MB。
- 如果只想先录入资料，可以点击“保存草稿”，草稿不会显示在前台。
